## 使用流程

### 首次使用

1. **启动应用**
   - 如未登录，自动打开设置页

2. **配置账号**（设置页）
   - 输入学号和密码
   - 点击"验证登录"

3. **配置邮件推送**（设置页，可选）
   - 输入邮件 API 地址
   - 输入 API Token
   - 点击"保存邮件配置"

4. **查询成绩**（查询页）
   - 选择学期
   - 点击"查询成绩"
   - 或点击"查看历史"查看所有成绩

5. **开启监控**（监控页）
   - 设置检查间隔（分钟）
   - 点击"开始监控"

### 日常使用

1. **启动应用**
   - 自动登录（如已保存配置）
   - 自动跳转首页

2. **查看统计**（首页）
   - 总课程数
   - 总学分
   - 平均绩点
   - 最近查询的5门课程

3. **快捷操作**（首页）
   - 点击"查询最新学期"跳转查询页
   - 点击"开始监控"跳转监控页

4. **成绩变化通知**
   - 监控检测到变化
   - 自动发送邮件到 `学号@mail.nankai.edu.cn`
   - HTML 格式，包含详细成绩信息


## 打包与分发

### Windows 打包
```bash
cd v3.0
flet build windows
```

生成的 exe 文件在 `dist/` 目录下。

### Android 打包
```bash
flet build apk
```

生成的 apk 文件在 `build/apk/` 目录下。

## 注意事项

1. **数据安全**
   - 密码明文保存在本地数据库（加密存储可后续添加）
   - 邮箱 SMTP 凭证仅存储在服务器端
   - API Token 需妥善保管

2. **网络要求**
   - 需要能访问南开 WebVPN（eamis.nankai.edu.cn）
   - 监控功能需持续网络连接
   - 邮件推送需访问自建 API 服务器

3. **性能建议**
   - 监控间隔建议 ≥ 30 分钟（避免频繁请求）
   - 长时间运行建议定期重启应用

4. **已知问题**
   - 监控运行时关闭应用可能需要等待线程结束
   - Android 版本未完整测试
